The software source code is licensed under the license specified in
the LICENSE file.

The “Crux” name, application logo, application icon, screenshots,
visual identity and other project branding are not granted for use as
the name or primary branding of derivative applications.

Modified or independently distributed versions must:

1. use a clearly distinct application name;
2. use a clearly distinct application icon and logo;
3. not imply affiliation with, endorsement by, or official status from
   the Crux project or its maintainers;
4. clearly identify themselves as independently maintained forks.

The name “Crux” may be used descriptively to state that a project is
based on or derived from Crux, provided that such use does not create
confusion about affiliation or endorsement.

## Relationship to OC Remote

Crux is an independently maintained fork of
[OC Remote](https://github.com/crim50n/oc-remote) and is not affiliated
with, endorsed by, or an official continuation of that project.

The “OC Remote” name, logo and icon remain the branding of the upstream
project and are not used by Crux. Crux ships its own name and its own
icon, as OC Remote's branding policy requires of forks. “OC Remote” is
used in this repository only descriptively, to identify the project Crux
is derived from.
